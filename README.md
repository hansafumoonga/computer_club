# Tech Explorers

A set of free browser games for a school computer club, to help children learn the keyboard, the mouse and Makey Makey.

**Play it:** https://hansafumoonga.github.io/computer_club/

It runs entirely in the browser. No install, no accounts, no server and no internet needed after the page has loaded. Nothing about the children is collected or saved.

---

## An honest note about how this was made

**This system was built with AI. The code was written entirely by Claude, an AI model made by Anthropic.**

The human part of this project was:

- the **ideas and the reasons**: what the learners need, what a computer club teacher wants, which skills matter;
- the **prompts**: describing in plain language what to build, what to change and why;
- the **testing and decisions**: trying it with real learners and with Makey Makey, reporting what felt wrong, and choosing what to keep.

No code was written by hand. Every file in this repository was generated by Claude from those instructions.

What that means for you:

- **Please do not expect a seamless or perfect system.** AI-written software can contain bugs, odd edge cases or choices a human developer might have made differently.
- **It has been tested and it works well.** It was checked with automated tests (bots that play every level in a real browser) and, more importantly, used by teachers and learners in a real club. A colleague tested it with a Makey Makey and it worked. Learners completed the games and enjoyed them, and the results were what we hoped for.
- **It is still growing.** More modules and improvements are planned, and the code may change over time.
- **Thoughts and feedback are very welcome.** If something breaks, feels confusing, or you have an idea, please open an Issue on this repository.

## What is in it

### Session 1: Year 1, 2 and 3 (normal keyboard and mouse)
- **Click & Type Quest**: a guided adventure of 10 levels that teaches the mouse (moving, clicking, choosing, drag and drop, connecting, double-click, right-click) and the keyboard (finding letters, small and BIG letters, Caps Lock, words, Space, Backspace, Enter). A friendly guide called Buddy shows each action first, then the learner tries, with gentle hints and stars. Finishing all 10 levels unlocks a printable **certificate**.
- **Builder Club**: build a car, a house, a rocket, a farm, a castle, a robot, a boat, a garden, an airport and finally a whole city. In **Type & Build** the child types each word to add a piece; in **Click & Build** they use the mouse (click, drag, double-click and right-click). Very gentle: hints and help appear by themselves, and every picture earns at least one star. Finishing all 10 pictures in one game unlocks a printable certificate.
- **Slice & Pop**: press the right letter to slice or pop.
- **Word Hunt**: a computer-words word search with 10 levels.
- **Jump Over!** and **Star Blaster**: simple arcade games with many levels.

### Session 2: Year 4, 5 and 6 (Makey Makey)
These games use only the five Makey Makey keys: Left, Up, Down, Right and Space.
- **Piano**: play, listen to and learn songs, including Christmas songs (Jingle Bells, Silent Night, Merry Christmas), with a backing beat and a recorder.
- **Jump Over!**, **Star Blaster**
- **Commando Run**: 15 stages with big creatures, ending with a dragon king.
- **Pattern Pop!**: watch, listen and copy.
- **Typing Club** (needs a full keyboard): 10 levels from the home row to capitals, punctuation and numbers, in three games: **Typing Racer** (race your own best time), **Word Blaster** (zap falling words) and **Boss Sentences** (type sentences to beat a friendly boss). A finger-guide keyboard shows which finger to use. Stars reward accuracy first; speed earns a separate medal. A teacher report shows words per minute, accuracy and the keys to practise. Finishing all 10 levels of any one game unlocks a printable **certificate** with a speed medal.

### For teachers
- A **pause** button in every game (the Escape key also works in the arrow-key games).
- Click & Type Quest has Year 1, 2 and 3 settings, an optional spoken voice, high contrast, slow animations and a click-to-place alternative to dragging, and a simple **teacher report** (stars per skill and suggested practice).
- A printable A4 **certificate** with a name box.
- Difficulty, speed, words and levels can be changed by editing plain numbers and lists. See `NOTES.txt`.

## Run it
- Visit the link above, or open `index.html` on your computer (double-click).
- Click a session, then a game. Press **F11** for full screen. Sound starts after the first click.

## Put your own copy on GitHub Pages
1. Push this folder to a GitHub repository.
2. In the repository go to **Settings, then Pages**, choose the `main` branch and the `/ (root)` folder, then Save.
3. Share `https://<your-name>.github.io/<repo-name>/`.

## Files
- `css/builder.css`, `js/builder_data.js`, `js/builder.js`: Builder Club (styling, the drawn pictures and their words, engine)
- `css/typing.css`, `js/typing_data.js`, `js/typing.js`: Typing Club (styling, levels and sentences, engine)
- `index.html`: the page
- `css/style.css`: styling for the whole system
- `css/skills.css`, `js/skills.js`, `js/skills_levels.js`: Click & Type Quest (engine and all level content)
- `js/`: one file per game, plus shared code (`core.js`, `music.js`, `sprites.js`, `sprites_world.js`, `main.js`)
- `NOTES.txt`: teacher notes (what to change, and where)

Plain HTML, CSS and JavaScript only. No libraries and no build step.

## Known limits
- **Progress is not saved.** It lasts only while the page is open, so download the teacher report or print the certificate before closing the tab.
- **The spoken voice** uses a voice already installed on the device. If a device has no English voice, the lessons still work with the words on screen.
- **Browsers:** it has been tested in Chrome. Other modern browsers should work but have not been checked as carefully.
- Because the code is AI-generated, there may be rough edges we have not found yet. Reports are appreciated.
